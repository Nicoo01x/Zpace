The window

Stop alt-tabbing around your agent.

Every project keeps its sessions, terminals, notes and layout. Close the app, open it a week later, and it is exactly where you left it.

01 — Editor

See what the agent wrote, as it writes it.

A real editor with a timeline: every file an agent touched, before and after, with "Ask Claude" one click away.

02 — Review

Keep the good lines, discard the rest.

A review pane over the session's changes. Keep or discard per file, per hunk — then commit.

03 — Git

Stage, commit, push. Without leaving.

Changes, branches and history in a side panel. Commit messages the agent can draft for you.

04 — Notes & boards

Think next to the work.

Notes with real formatting and boards with cards you can drag — per project, searchable, and readable by your agents.

Agents, rooms, arena

Not one assistant. A team.

Agents are personas on top of Claude Code — their own instructions, skills, knowledge and servers. Put several in a room. Race them in an arena.

Agents

A reviewer, a designer, a release manager. Each with its rules, its library of documents, its MCP servers and tools. One click to chat with any of them in the current project.

Rooms

Several agents, one conversation. Mention @E2E-Reviewer and they answer each other, hand things off, and disagree when they should.

Arena

The same task, several variants, each in its own worktree. Compare the diffs side by side, pick one, merge. The losers vanish.

Plugins

Make it yours. Or make one.

A library inside the app, fed by an open registry. Panes, island readouts, palette commands, agents, skills, themes — anyone can publish one with a pull request, under their own name.

A plugin is a folder.

A plugin.json, a script with activate(zpace), maybe an HTML pane. The API is permission-gated by the manifest, documented in the registry, and the app shows who made it.

Read the plugin API 
export function activate(zpace) {
  // a readout in the island
  zpace.island.set({ icon: '🍅', text: '24:58', onClick: card });

  // a card with buttons when it is clicked
  const card = () => zpace.island.show({
    title: 'Focus block', lines: ['24:58 left'],
    buttons: [{ label: 'Pause', primary: true, run: pause }],
  });

  // and a palette command
  return zpace.commands.register({ id: 'start', title: 'Focus: start', run: start });
}

Free. Forever. Local.

No account. No cloud. No telemetry. Nothing leaves your machine unless you ask — updates come from GitHub releases, plugins from an open registry, and the code is there to read.

Signed installers for the three platforms. The app checks for updates at launch and shows you the notes before it does anything.
