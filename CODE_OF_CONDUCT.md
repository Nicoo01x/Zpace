# Code of conduct

Be decent. Concretely:

- Assume good faith. Ask before you accuse; explain before you dismiss.
- Criticise the code, the design, the idea — never the person.
- No harassment, no slurs, no personal attacks, no publishing anyone's private information. Not in issues, not in pull requests, not in plugins.
- Newcomers get patience. Nobody was born knowing Tauri.

The maintainer may edit, hide or delete content and block accounts that break this, without a debate. If something happens to you here, write to the maintainer through GitHub — it will be handled privately.
